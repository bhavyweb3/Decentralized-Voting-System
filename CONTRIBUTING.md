# Contributing

Thank you for your interest in contributing to the **Decentralized Voting System Using Blockchain Technology** project.

This project is developed for academic and educational purposes. Contributions that improve the code, documentation, security, or user experience are welcome.

## 🚀 How to Contribute

### 1. Fork the Repository

Create a fork of this repository on GitHub.

### 2. Clone the Repository

```bash
git clone https://github.com/YOUR-USERNAME/YOUR-REPOSITORY.git
```

### 3. Create a Branch

Create a new branch for your changes:

```bash
git checkout -b feature-name
```

### 4. Make Your Changes

You can contribute by:

* Fixing bugs
* Improving the website
* Improving the voting system
* Improving smart contracts
* Adding new features
* Improving documentation
* Improving security
* Adding or improving tests

### 5. Test Your Changes

Before submitting your changes, make sure the project works correctly.

Check:

* MetaMask connection
* Voting functionality
* Smart contract functionality
* Ganache/Sepolia connection
* MySQL connection if required

### 6. Commit Your Changes

Use a clear commit message:

```bash
git add .
git commit -m "Improve voting functionality"
```

### 7. Push Your Changes

```bash
git push origin feature-name
```

### 8. Create a Pull Request

Open the repository on GitHub and create a **Pull Request**.

Explain:

* What you changed
* Why you changed it
* How you tested it

## 🔐 Security

Please **do not upload**:

* MetaMask private keys
* MetaMask recovery phrases
* Passwords
* MySQL passwords
* API keys
* Personal information
* `.env` files containing secrets

## 📝 Code Guidelines

* Keep the code simple and readable.
* Use meaningful variable and function names.
* Add comments where necessary.
* Test your changes before submitting them.
* Do not make unnecessary changes to unrelated files.

## 🐛 Reporting Issues

If you find a bug, create an **Issue** on GitHub and provide:

* Description of the problem
* Steps to reproduce it
* Error message, if any
* Screenshot, if useful

## 🤝 Code of Conduct

Please be respectful and professional when communicating with other contributors.

Thank you for helping improve this project! ❤️
